**Shadow Prompt Bot** هي أداة قوية لإنشاء برومبتات (أوامر) خارقة لكسر قيود نماذج الذكاء الاصطناعي مثل ChatGPT و Gemini و Claude وغيرها.

- ✅ **تثبيت تلقائي** لجميع المكتبات المطلوبة
- ✅ **بوت تلغرام تفاعلي** مع أزرار سهلة
- ✅ **4 أنواع من البرومبتات القوية**:
  - 🔥 برومبت هاك - خبير اختراق
  - 💻 برومبت كود - مطور خارق
  - 💀 برومبت كسر (Shadow Mode V99)
  - 🎨 برومبت إبداعي
- ✅ **قائمة سرية** بأوضاع متطورة
- ✅ **حفظ البرومبتات** لكل مستخدم
- ✅ **تصدير البرومبتات** كملفات نصية
